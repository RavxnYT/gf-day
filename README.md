# Girlfriend's Day 💕

A romantic, highly animated single-page love letter for Girlfriend's Day (August 1).

## Customize (2 minutes)

Open `config.js` and edit:

- `herName` — her name (big in the hero)
- `yourName` — your signature
- `letter` — the love letter text
- `reasons` — why you love her
- `moments` — little memory lines

That's it. No build step.

## Launch on GitHub Pages

1. Push this repo to `https://github.com/RavxnYT/gf-day`
2. On GitHub: **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / folder: `/ (root)` → Save
5. Site will be live at: `https://ravxnyt.github.io/gf-day/`

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```
